车间实拍照片放置说明（关于我们 / 车间实拍板块）
==================================================

「关于我们」页面的「车间环境实拍」照片墙引用了以下 4 张图片：

  img/workshop/01.jpg  →  厂房全景
  img/workshop/02.jpg  →  精密磨削产线
  img/workshop/03.jpg  →  超精机精研工位
  img/workshop/04.jpg  →  合套仪全检工位

使用方法：
  1. 将此目录中的 4 张真实车间照片按上述文件名命名（或改成你自己的文件名，
     同时更新 about.html 中对应的 <img src="img/workshop/XX.jpg">）。
  2. 建议横屏拍摄、16:9 或 4:3 比例、宽 ≥ 800px、单张 < 500KB。
  3. 刷新 about.html 页面即可看到真实照片，替换掉默认的占位图标。

注意：未放入照片时，页面会显示带「厂房全景 / 磨削产线…」字样的占位卡片，
      布局不受影响，不会出现破图。

车间实拍视频（首页、生产能力页、关于我们页共用）：
  将视频文件命名为 video/workshop.mp4 放到 website/video/ 目录，
  并可选放 video/workshop-poster.jpg 作封面。
  视频建议横屏 16:9、时长 15–60 秒、建议 < 20MB。
